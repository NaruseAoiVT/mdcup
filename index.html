APPEARANCE

外観

画像は公開URLを指定します。GitHub Pagesの同じリポジトリに置いた場合は bg/day1.jpg のような相対パスでも動きます。背景画像は画面上部の黒い帯に表示されます。

文字色と背景のコントラストが不足しています。 このままだと参加者が読みにくくなります。文字色を明るくするか、背景の暗さを上げてください。
画像そのものはURLに埋め込めません。 base64にすると設定URLが数百KBになり、告知に貼れなくなります。画像はリポジトリか画像ホスティングに置いて、そのURLを指定してください。

BASIC

基本

SEASONS

除外シーズン

最高到達ランクの判定から外すシーズンです。番号を押して切り替えます。

S17・S12・S19 はランクがインフレしたシーズンとして、多くの主催が除外しています。 除外シーズンを指定するのは主催の標準的な運用です。ここを空にすると、盛りやすかったシーズンのマスターがそのまま通ります。

START BONUS

開始ボーナス

使い切らなかったptを、試合開始時の持ち点に変換します。

編成の自由を奪わずに、上に寄せた編成との差を吸収できます。 上限いっぱいまで使ったチームは持ち点ゼロ、余らせたチームは先行してスタートします。集中編成を禁止する必要がなくなります。

RANK POINTS

ランクごとのポイント

チェックを外したランクは出場不可になり、参加者の選択肢から消えます。

最高ランクは8ptに置いてください。 KD補正の+2と合わせてちょうど10ptに届きます。最高ランクを10ptにすると、上位帯だけKD加点が頭打ちで消えます。

KD

KD補正

トータルKDの区切りごとの加算・減算です。

PREDATOR

プレデターの到達区分

プレデターを選んだ参加者にだけ表示される選択肢です。ランク基準からの増減を設定します。

プレデターは上位750位の椅子取りです。 到達しただけの「タッチ」と、スプリットを維持しきった層では実力が違います。維持組にはプレデターバッジが残り、両スプリット維持なら光るバッジになるので、スクリーンショットで判別できます。タッチのみの申告はバッジが存在しないことで確認できます。

COMPETITIVE

競技経験の加算

ALGS チャレンジャーサーキット（CC）で何ラウンドまで勝ち上がったかの加算です。参加者は競技経験にチェックを入れると、この一覧から選ぶ形になります。

CCは各ラウンドで上位10チームだけが次に進みます。 だからラウンド数がそのまま実力の段階になります。ブラケットの正式名称は年度で変わるので、参加者には「何ラウンド勝ち上がったか」を申告してもらう形にしています。
